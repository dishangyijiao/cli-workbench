# Usage evidence

This is a lightweight log of **real use and observed outcomes**, not a feature backlog or another specification. The product's documented behavior, setup and safety rules live in [README.md](README.md) and [docs/architecture.md](docs/architecture.md). Do not copy them here.

## Problem

I want one reproducible terminal workspace when replacing or switching computers, and one place to supervise CLI coding agents across projects. Configuration portability and safe recovery matter more than adding features.

## Usage

Record an actual session, migration or recovery exercise when it happens. The repository's automated tests demonstrate specified behavior in controlled environments; they do not establish that my personal machine migration succeeded.

## Outcome

**Not measured yet.** Track setup time on a clean machine, whether existing configuration is recoverable, and how much manual attention a real multi-agent task requires. State failures as well as successes.

## Friction

**To observe:** installation dependencies, machine-specific settings, agent state handoffs, interrupted work, and recovery after a mistaken config change. Record what actually blocks a workflow; do not infer a user problem from a desired feature.

## Evidence

Prefer timestamps, reproducible commands, sanitized output and links to relevant issues/PRs. CI results and test assertions are engineering evidence, **not** proof of personal productivity improvement. Never record API keys, private paths, session transcripts or identifying machine details in this public repository.
